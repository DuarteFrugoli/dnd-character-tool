## Contributing

At the moment, this project accepts community contributions only for translation files located in `assets/data/i18n/`.

Code contributions, feature implementations, design changes, and non-translation assets are not currently accepted unless previously discussed and explicitly approved by the maintainer.

By submitting a translation contribution, you agree to license your contribution under CC BY 4.0. This allows the contribution to be used, modified, distributed, and included in both free and commercial versions of this project, with appropriate attribution.
